# AVELUNE ✦

Платформа поиска и сравнения косметики — демоверсия V4.

## Запуск

Откройте `index.html` в обычном браузере либо используйте VS Code с расширением Live Server.

## GitHub Pages

В репозитории откройте **Settings → General → Danger Zone → Change repository visibility** и переключите **Private → Public** (если нужна бесплатная публичная страница).

Затем откройте **Settings → Pages**:
1. Build and deployment → Source: **Deploy from a branch**
2. Branch: **main**, folder: **/(root)**
3. Нажмите **Save**.

Сайт будет доступен по адресу `https://hiqyho-sys.github.io/AVELUNE/` после успешной публикации.

## Что работает

- Каталог косметики, поиск по брендам и названиям
- Фильтры, сортировка, избранное, сравнение
- Светлая и тёмная тема, анимации, мобильная навигация

**Внимание:** все предложения и цены в статической версии демонстрационные, не отражают реальные остатки и не обновляются. Сервер SQLite и импорт фидов НЕ работают на GitHub Pages — для них требуется отдельный хостинг.
